适用变更：`openspec/changes/rag-explained-judgment-concession`

## 建议执行顺序

1. 阅读 `02_全流程测试方案.md`，确认环境、测试范围和验收口径。
2. 按 `01_人工测试操作手册.md` 完成环境启动、登录、标准维护和基础连通性检查。
3. 按 `04_测试数据与PDF映射.md` 建立核心测试标准并上传PDF。
4. 执行 `03_人工测试用例.md` 的 P0 核心场景。
5. 用 `05_执行记录模板.md` 记录每轮执行结果、问题和证据截图路径。

## 关键提醒

- 结构化标准指标仍是自动判定唯一依据；PDF/RAG文本只用于引用、解释和人工复核。
- 标准发布后才应进入RAG检索；草稿源文件不应被检索到。
- 同优先级标准冲突应阻断正式出证；裁决必须人工完成。
- AI可解释、建议和预填，但不得自动审批让步、改判、复检或出证。
- 核心人工测试统一使用隔离字段 `Q235B-QA0622`、`CUST-002`、标准编号后缀 `QA0622`，避免匹配系统历史脏数据中的 `Q235B/CUST-001/STD001/STD003`。
