# 人工测试用例

## 1. 执行前置

前置数据按 `04_测试数据与PDF映射.md` 建立。

为避开系统历史脏数据，核心用例只使用 `冷轧板 / Q235B-QA0622 / CUST-002` 组合，以及带 `QA0622` 后缀的标准编号。PDF文件名和标准名称中出现的原始 `Q235B` 仅表示模拟PDF正文，不作为结构化录入字段。

核心执行顺序建议：

1. `STD-001` 建国标并上传发布PDF。
2. `STD-002` 建客户协议V1并上传发布PDF。
3. 执行 `RAG`、`QUAL`、`UNQUAL`、`CONC`。
4. `STD-003` 建客户协议V2冲突样本并发布。
5. 执行 `CONFLICT`。

步骤：

1. 标准库新增标准，录入 `04` 中 `STD-N-Q235B-001` 数据。

期望：

- 源文件名正确。
- `parseStatus` 成功。
- `indexStatus=INDEXED`。
- `chunkCount > 0`。

## 4. 合格场景

### QUAL-001 Q235B-QA0622国标合格

| 字段 | 内容 |
| --- | --- |
| 目标 | 验证结构化规则判定合格、解释引用国标PDF、质保书问答可出证 |
| 前置 | 仅发布 `STD-001` 和 `STD-002`，不要发布冲突V2 |
| 客户 | 留空 |
| 品种/牌号 | 冷轧板 / Q235B-QA0622 |
| 规格 | `厚度0.50mm-3.00mm，宽度600mm-1500mm` |
| 炉号 | `HT-MAN-QUAL-001` |
| 卷号 | `FT-QUAL-001` |
| 样品类型 | 中部 |
| 检验时间 | 当前时间 |
| 指标值 | Rm=430，A=30.5，ReL=280，Δt=0.05 |
| 预期判定 | `QUALIFIED` |

步骤：

1. 进入检验录入。
2. 填写基础信息。
3. 点击“从标准加载”，选择/加载国标指标。
4. 填写指标值并提交。
5. 点击“查看判定详情”。
6. 打开质保书问答，卷号输入 `FT-QUAL-001`，问题输入 `这卷为什么能出证？`。

期望：

- 判定结果为 `QUALIFIED`。
- 判定解释中标准命中为国标。
- 指标明细显示所有指标在合格范围内。
- 来源引用能看到国标PDF来源。
- 质保书问答为最终可出证或明确说明可正式出证。

## 5. 不合格场景

### UNQUAL-001 客户协议下抗拉强度低于让步下限

| 字段 | 内容 |
| --- | --- |
| 目标 | 验证客户协议优先且超出让步范围时判不合格 |
| 前置 | 发布 `STD-001`、`STD-002`；不要发布冲突V2 |
| 客户 | `CUST-002` |
| 品种/牌号 | 冷轧板 / Q235B-QA0622 |
| 规格 | `厚度0.80mm-2.50mm，宽度800mm-1250mm` |
| 炉号 | `HT-MAN-UNQ-001` |
| 卷号 | `FT-UNQUAL-001` |
| 指标值 | Rm=360，A=27，ReL=260，Δt=0.03 |
| 预期判定 | `UNQUALIFIED` |

步骤：

1. 进入检验录入。
2. 客户选择 `CUST-002`。
3. 规格选择客户协议规格。
4. 从标准加载指标。
5. 填写指标值并提交。
6. 打开判定解释。
7. 打开质保书问答，问 `这卷能否生成正式质保书？`。

期望：

- 客户协议优先于国标。
- Rm=360 低于客户协议让步下限370，结果为 `UNQUALIFIED`。
- 判定解释引用客户协议PDF。
- 质保书问答拒绝正式出证。

## 6. 可让步场景

### CONC-001 客户协议下轻微偏差进入让步评审

| 字段 | 内容 |
| --- | --- |
| 目标 | 验证合格限外、让步限内时判 `CAN_CONCESSION`，并生成风险评估 |
| 前置 | 发布 `STD-001`、`STD-002`；不要发布冲突V2 |
| 客户 | `CUST-002` |
| 品种/牌号 | 冷轧板 / Q235B-QA0622 |
| 规格 | `厚度0.80mm-2.50mm，宽度800mm-1250mm` |
| 炉号 | `HT-MAN-CONC-001` |
| 卷号 | `FT-CONC-001` |
| 指标值 | Rm=372，A=26，ReL=250，Δt=0.09 |
| 预期判定 | `CAN_CONCESSION` |

步骤：

1. 进入检验录入并选择 `CUST-002`。
2. 从客户协议标准加载指标。
3. 填写指标值并提交。
4. 打开判定解释。
5. 点击让步相关入口，触发AI风险评估。
6. 质保书问答输入卷号 `FT-CONC-001`，问 `这卷当前能否生成正式质保书？`。

期望：

- 判定结果为 `CAN_CONCESSION`。
- 指标明细显示 Rm/A 超出合格限但在让步限内。
- 让步风险输出 `riskLevel`、`mustReview`、证据引用、建议条件。
- AI不会自动审批让步。
- 质保书问答提示非最终或仅可预览，待让步审批/客户确认。

## 7. 标准冲突场景

### CONFLICT-001 同客户协议Rm下限冲突

| 字段 | 内容 |
| --- | --- |
| 目标 | 验证同优先级客户协议冲突阻断判定和正式出证 |
| 前置 | 发布 `STD-001`、`STD-002`、`STD-003` |
| 客户 | `CUST-002` |
| 品种/牌号 | 冷轧板 / Q235B-QA0622 |
| 规格 | `厚度0.80mm-2.50mm，宽度800mm-1250mm` |
| 炉号 | `HT-MAN-CF-001` |
| 卷号 | `FT-CONFLICT-001` |
| 指标值 | Rm=382，A=28，ReL=270，Δt=0.02 |
| 冲突点 | V1 Rm下限375 vs V2 Rm下限390 |
| 预期判定 | `STANDARD_CONFLICT` |

步骤：

1. 发布客户协议V2冲突样本。
2. 进入检验录入，选择 `CUST-002` 和客户协议规格。
3. 从标准加载指标并填写值。
4. 提交检验。
5. 打开判定解释。
6. 进入标准冲突检测，筛选 `PENDING` + `BLOCKING`。
7. 打开冲突详情。
8. 打开质保书问答，问 `为什么不能出正式质保书？`。
9. 回到冲突详情，选择控制标准V2或V1，填写裁决理由，提交裁决并重判。

期望：

- 初始判定为 `STANDARD_CONFLICT`。
- 判定解释显示低置信或冲突警告，不给最终放行结论。
- 冲突详情展示两个客户协议标准和Rm下限差异。
- 未裁决前质保书问答阻断正式出证。
- 裁决后冲突状态变为已处理，记录重判ID。
- 重判后再次打开解释，不再显示未解决冲突阻断。
