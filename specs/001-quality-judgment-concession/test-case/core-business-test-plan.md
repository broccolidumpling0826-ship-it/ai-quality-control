## 一、测试方案总览

### 1.1 测试目标

本测试方案旨在验证质量判定解释与让步管理系统的 5 条核心业务需求，确保系统能够准确、稳定地支撑钢铁产品从标准维护、检验录入、自动判定、复检改判到质保书生成的完整质量管控业务链路。

具体目标如下：

1. 验证质量标准（国标、企标、客户协议）的新增、编辑、发布、作废等全生命周期管理功能正确；
2. 验证检验记录的录入、批量导入、软作废等操作功能正确，且触发正确的自动判定逻辑；
3. 验证自动判定引擎依据三级标准优先级，对4种判定结论（合格、不合格、可让步、需复检）给出正确判定；
4. 验证复检流程（最多2次）与改判流程（含常规改判、逆向改判）的权限控制及审批链路；
5. 验证质保书汇总功能按卷号/批次号汇总正确，快照内容完整，历史快照可追溯。

### 1.2 测试范围（5 条核心需求）

| 需求编号 | 需求名称 | 范围说明 |
|----------|----------|----------|
| REQ-01 | 质量标准维护 | 国标、企标、客户协议三类标准的 CRUD、发布、时间窗口校验、作废 |
| REQ-02 | 检验记录录入 | 单条新增、批量导入、软作废、权限控制 |
| REQ-03 | 自动判定引擎 | 四种判定结论、标准三级优先级、无标准覆盖处理、判定解释详情 |
| REQ-04 | 复检与改判管理 | 复检流程（≤2次）、常规改判、逆向改判（含证据上传）、审批权限 |
| REQ-05 | 质保书生成 | 按卷号/批次号汇总、指标类别过滤、作废排除、让步附注、历史快照 |

**范围外（本方案不覆盖）：**
- 系统管理（用户管理、组织架构配置）
- 报表统计与数据导出
- 性能压力测试

### 1.5 测试类型与策略

| 测试类型 | 策略说明 | 覆盖需求 |
|----------|----------|----------|
| 功能测试 | 按测试用例逐条验证业务逻辑正确性 | REQ-01 ~ REQ-05 |
| 边界值测试 | 对指标上下限、时间窗口边界、复检次数上限进行边界测试 | REQ-01、REQ-03、REQ-04 |
| 权限测试 | 使用低权限/无权限账号执行受限操作，验证返回 403 | REQ-01、REQ-02、REQ-04 |
| 负向测试 | 输入非法数据、重叠时间窗口、超出限制条件等，验证系统报错提示 | REQ-01、REQ-04 |
| 端到端测试 | 模拟完整业务场景，验证跨模块数据流转一致性 | 全部 |
| 回归测试 | 标准作废后验证历史判定记录不受影响 | REQ-01、REQ-03 |

**测试执行顺序：**
1. 先执行数据初始化（见第二章）
2. 按需求顺序执行：REQ-01 → REQ-02 → REQ-03 → REQ-04 → REQ-05
3. 最后执行端到端场景测试（第四章）

### 1.6 通过/失败标准

**通过标准：**
- P0 级用例：100% 通过（零缺陷）
- P1 级用例：≥ 95% 通过
- P2 级用例：≥ 90% 通过
- 所有安全/权限相关用例：100% 通过
- 端到端场景：全部 4 个场景完整执行通过

**失败标准（需停止测试、提交阻塞性缺陷）：**
- 任意 P0 用例失败
- 自动判定引擎给出错误判定结论
- 数据库出现脏数据（如作废记录被纳入质保书汇总）
- 权限控制失效（低权限账号成功执行受限操作）

### 2.4 检验值测试矩阵（4 个判定场景）

| 场景编号 | 场景描述 | Rm (MPa) | ReL (MPa) | C% | 厚度偏差 (mm) | 适用标准 | 预期判定结论 |
|----------|----------|----------|-----------|----|--------------|---------:|-------------|
| 场景1 | 全部合格 | 420 | 260 | 0.15 | +0.08 | 客户协议优先 | QUALIFIED（合格） |
| 场景2 | 不合格（低于让步下限） | 340 | 220 | — | — | 国标 | UNQUALIFIED（不合格） |
| 场景3 | 可让步（低于客协下限，但在让步范围内） | 362 | — | — | — | 客户协议 | CAN_CONCESSION（可让步） |
| 场景4 | 需复检（低于客协下限，无让步范围配置） | 350 | — | — | — | 国标（该指标未配置让步） | NEED_RECHECK（需复检） |

**判定逻辑说明：**
- 场景1：Rm=420 在客协 [380, 490] 范围内，ReL=260 ≥ 客协下限 240，C%=0.15 ≤ 客协上限 0.18，厚度偏差 +0.08 在客协 ±0.10 范围内，全部合格 → QUALIFIED
- 场景2：Rm=340 低于让步下限 360，不可让步 → UNQUALIFIED
- 场景3：Rm=362 低于客协下限 380，但 ≥ 让步下限 360 → CAN_CONCESSION
- 场景4：Rm=350 低于国标下限 370，该品种/牌号在国标中未配置让步范围 → NEED_RECHECK

### 3.1 需求1：标准维护测试用例（TC-B001 ~ TC-B006）

**TC-B001: 新增国家标准并配置三项指标**

| 字段 | 内容 |
|------|------|
| 用例编号 | TC-B001 |
| 所属需求 | 需求1: 质量标准维护 |
| 优先级 | P0 |
| 前置条件 | 以质检主管账号 `qc_manager` 登录系统；品种"冷轧板"、牌号"Q235B"已在基础数据中存在；指标项目 Rm、ReL、C% 已在指标库中存在 |
| 测试数据 | 标准编号：GB/T 700-2006；牌号：Q235B；Rm [370, 500] 让步 [360, 510]；ReL 下限 235；C% 上限 0.22% |
| 验证方法 | UI 验证 + DB 验证 |

**操作步骤：**

1. 打开浏览器，访问 `http://localhost:3000`，输入账号 `qc_manager` / 密码 `Qc@123456`，点击「登录」按钮。
2. 登录成功后，在左侧导航菜单中点击「质量管理」→「标准维护」，进入标准列表页面。
3. 点击页面右上角「新增标准」按钮，弹出新增标准对话框。
4. 在对话框中填写以下信息：
   - 标准编号：`GB/T 700-2006`
   - 标准名称：`碳素结构钢`
   - 标准类型：选择下拉项「国家标准」
   - 适用品种：选择下拉项「冷轧板」
   - 适用牌号：选择下拉项「Q235B」（品种选择后牌号下拉联动刷新）
   - 适用规格：选择「全规格」
   - 生效日期：点击日期选择器，选择 `2006-01-01`
   - 失效日期：点击日期选择器，输入 `9999-12-31`
5. 点击「下一步」或「保存基本信息」按钮，进入指标配置子页面。
6. 点击「添加指标」按钮，添加第一个指标：
   - 指标项目：选择「抗拉强度 (Rm)」
   - 下限值：`370`，单位：`MPa`
   - 上限值：`500`，单位：`MPa`
   - 让步下限：`360`，单位：`MPa`
   - 让步上限：`510`，单位：`MPa`
   - 点击「确认」
7. 再次点击「添加指标」，添加第二个指标：
   - 指标项目：选择「屈服强度 (ReL)」
   - 下限值：`235`，单位：`MPa`
   - 上限值：留空（无上限）
   - 让步下限/上限：留空
   - 点击「确认」
8. 再次点击「添加指标」，添加第三个指标：
   - 指标项目：选择「碳含量 (C%)」
   - 下限值：留空（无下限）
   - 上限值：`0.22`，单位：`%`
   - 让步下限/上限：留空
   - 点击「确认」
9. 检查指标列表，确认已显示 3 行指标配置。
10. 点击「提交」按钮，完成新增。

**预期结果：**

1. 提交后系统提示「标准新增成功」（或页面跳回列表）。
2. 标准列表中出现一条标准编号为 `GB/T 700-2006` 的记录，状态显示为「草稿」。
3. 查询数据库 `quality_standard` 表，存在 `std_code = 'GB/T 700-2006'`，`status = 'DRAFT'` 的记录。
4. 查询数据库 `quality_standard_item` 表，存在关联该标准的 3 条指标记录，Rm 的 `concession_lower = 360`，`concession_upper = 510`。

### 场景四: 可让步→让步接收→质保书（P1 让步场景）

**场景描述：** 模拟一卷钢板检验结果为「可让步」，经内部审核、客户确认，完成让步接收，最终生成含让步说明的质保书。

---

**步骤 1 - 录入可让步检验数据**

1. `qc_user01` 登录，新增检验记录：
   - 炉号：`F2025050003`，卷号：`Z2025050003-01`，批次：`F2025050003`
   - 客户：华东汽车配件，品种：冷轧板，牌号：Q235B
   - Rm=`362`（低于客协下限 380，但 ≥ 让步下限 360），其余指标合格
2. 提交后确认判定结论为「可让步（CAN_CONCESSION）」。

**步骤 2 - 发起让步申请**

3. `qc_manager` 登录，进入 F2025050003 详情页，点击「发起让步」。
4. 填写让步申请：
   - 让步指标：Rm，实测值 362，标准要求 [380, 490]
   - 让步理由：`Rm偏差在允许让步范围内，经评估不影响产品使用性能`
   - 让步有效期：当前日期 + 90天
5. 提交让步申请，等待内部审批。

**步骤 3 - 内部审核（双签）**

6. `qc_manager` 自身作为第一签批人审核通过（或由系统配置的审核人审批）。
7. `quality_director` 登录，作为第二签批人，进入让步审批列表，找到该申请，点击「审批通过」，意见：`让步范围合理，批准`。

**步骤 4 - 客户确认**

8. 系统向客户（华东汽车配件）发送让步确认请求（可通过「销售人员」账号 `sales_user01` 代替操作客户确认）。
9. `sales_user01` 登录，进入「让步确认」功能，找到 F2025050003 的让步请求，代客户点击「客户确认接收」，备注：`客户已电话确认接收`。
10. 让步状态变更为「已接收（ACCEPTED）」。

**步骤 5 - 生成含让步说明的质保书**

11. `qc_user01` 登录，进入「质保书管理」，按卷号 `Z2025050003-01` 汇总。
12. 查看质保书：
    - 判定结论：合格（含让步接收，标注 Rm 超标但已让步接收）
    - 让步说明区域显示：让步指标 Rm，实测 362 MPa，标准 380 MPa，让步批准人，客户确认标记
13. 点击「确认生成」，保存质保书快照。

**步骤 6 - 验证逆向改判联动让步失效（扩展验证）**

14. 若后续发起逆向改判（合格→不合格），验证已接收的让步状态自动变为「已失效」（参考 TC-B033）。

**预期结果总结：**
- 可让步检验记录正确触发让步流程
- 双签审批和客户确认均完整记录
- 质保书中正确附加让步说明，合规可追溯
- 逆向改判联动让步失效机制有效
