### 3.1 判定结论徽章颜色规范

| 结论值 | 含义 | 徽章颜色 |
|--------|------|----------|
| QUALIFIED | 合格 | 绿色 (#52C41A) |
| UNQUALIFIED | 不合格 | 红色 (#FF4D4F) |
| CAN_CONCESSION | 可让步 | 橙色 (#FA8C16) |
| NO_STANDARD | 无标准覆盖 | 灰色 (#8C8C8C) |

### 3.2 改判 is_reverse 判断矩阵

| 源结论 | 目标结论 | is_reverse |
|--------|----------|------------|
| UNQUALIFIED | QUALIFIED | false（常规） |
| UNQUALIFIED | CAN_CONCESSION | false（常规） |
| QUALIFIED | UNQUALIFIED | true（逆向） |
| QUALIFIED | CAN_CONCESSION | true（逆向） |
| CAN_CONCESSION | UNQUALIFIED | true（逆向） |
| CAN_CONCESSION | QUALIFIED | true（逆向） |
| 任意 | 同结论 | 禁止提交 |

### 3.3 让步签批流程状态机

```
发起申请 → PENDING_SALES
  → SALES_APPROVED（销售经理签批通过）
    → APPROVED（质量经理签批通过）
      → 待客户确认 → 客户确认/拒绝
  → REJECTED（任一环节拒绝）
  → EXPIRED（有效期到期）
  → VOIDED（关联改判通过）
```

### 3.4 复检次数限制规则

| 复检次数 | 允许操作 |
|----------|----------|
| 0 次 | 可发起第1次复检 |
| 1 次完成 | 可发起第2次复检 |
| 2 次完成 | 禁止继续复检，须走改判流程 |
