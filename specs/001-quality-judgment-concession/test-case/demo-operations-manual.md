## 四、演示流程一：全链路合格判定与质保书出具

> **业务场景**: 质量工程师录入 Q235B 冷轧板（华东汽车配件）检验数据，系统自动匹配客户协议标准，判定为合格，最终生成质保书数据。  
> **演示数据**: 数据集 A（F-DEMO-001 / Z-DEMO-001-01）  
> **预计耗时**: 约 8 分钟

### Step 2 — 录入检验记录

**菜单路径**: 检验录入（/inspection）→ 点击「新建检验记录」

按以下顺序填写表单：

**基本信息**：

| 字段 | 填写内容 | 说明 |
|------|---------|------|
| 炉号 | `F-DEMO-001` | 填写后批次号自动同步 |
| 卷号 | `Z-DEMO-001-01` | |
| 批次号 | `F-DEMO-001` | 系统自动填入，无需手动修改 |
| 客户 | 华东汽车配件有限公司 | 选择/输入 CUST-001 |
| 品种 | 冷轧板 | 从下拉框选择 |
| 牌号 | Q235B | 从下拉框选择 |
| 规格 | 厚度1.5mm，宽度1000mm | **从下拉框选择**（下拉联动品种+牌号后出现） |
| 样品类型 | 头部样（HEAD） | 从下拉框选择 |
| 检验时间 | 2026-06-01 09:00:00 | 选择日期时间 |

> 💡 **演示要点**: 点击「规格」下拉框，展示联动效果——系统根据已选品种+牌号自动过滤出有效规格列表，显示格式为"厚度1.5mm，宽度1000mm (C-HUA-2025-001)"。

**指标录入**：

点击「从标准加载」→ 系统自动带出该客户/品种/牌号下的标准指标（含上下限），然后依次输入实测值：

| 指标名称 | 输入实测值 |

| 抗拉强度 | `420` |
| 屈服强度 | `260` |
| 碳含量 | `0.15` |

点击「提交检验」。

**预期结果**: 页面弹出判定结论对话框，显示：
- 判定结论徽章：**绿色「合格」**（QUALIFIED）
- 匹配标准：C-HUA-2025-001（客户协议，优先于国标）
- 各指标偏差值均为正值（在合格范围内）

---

### Step 3 — 查看判定解释

点击弹窗中的「查看判定详情」（或通过菜单：判定解释 → 找到刚录入的记录，点击「查看判定」）
